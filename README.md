## Android app

A one-page Android app that shows "Ruby Dew Nectar".

**Get the APK:** open the repo's **Actions** tab, pick the latest **Build APK** run,
and download `ruby-dew-nectar-apk` under **Artifacts**. Unzip it and install
`app-debug.apk` on your phone (allow "install unknown apps" when asked).

**Build locally** (needs the Android SDK): `./gradlew assembleDebug`
