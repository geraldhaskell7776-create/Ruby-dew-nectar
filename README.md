## Android app

A one-page Android app that shows "Ruby Dew Nectar".

**Get the APK:** download it here:
https://github.com/geraldhaskell7776-create/Ruby-dew-nectar/releases/latest/download/ruby-dew-nectar.apk

Open the file on your phone and allow "install unknown apps" when asked.

**Build locally** (needs the Android SDK): `./gradlew assembleDebug`
